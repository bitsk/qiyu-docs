# 构建与发布

内核保留真实主线历史，按子系统提交。运行时拆分以来源清单和固定提交装配，不以复制旧 build 目录作为维护方式。

组合系统 manifest 固定系统来源、设备型号、功能 profile、全部组件 Git 提交、API 版本与产物 SHA-256。Debian、SteamOS 与后续系统的构建和设备验收分别记录。

当前源码拆分不改变已验证设备基线；离线构建、设备功能、物理佩戴与长时稳定性分别描述。已发布标签、Release 和上一次可用回退保留。

源代码仓库说明如何构建本组件，跨仓库指南及迁移记录保存在本 Wiki/Blog。
